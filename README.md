# Кинорекомендатель (Movie Recommendation App)

Веб-приложение для подбора фильмов и сериалов по указанным критериям (жанр, год, рейтинг, длительность, актёры).

## Возможности

- Регистрация и авторизация пользователей
- Анкетирование по критериям (жанр, год, рейтинг, длительность, актёры)
- Поиск фильмов по названию
- Персональные рекомендации на основе оценок
- История просмотров
- Оценка фильмов
- Страница "Мои оценки" с возможностью удаления
- Пагинация (подгрузка фильмов по 20 штук)
- Интеграция с TMDb API для загрузки фильмов
- Веб-интерфейс (HTML/CSS/JS)
- Адаптивный дизайн

## Технологии

- **Backend:** ASP.NET Core 8 (C#)
- **Database:** SQLite + Entity Framework Core
- **API:** TMDb API
- **Frontend:** HTML, CSS, JavaScript
- **Tools:** Visual Studio 2022, Swagger
